# 7 How is a program organised?

How data and the functions that work on it are grouped and shaped. Two building blocks of data:
* Records: this AND this AND this (a customer has a name and an email and a balance).
* Choice types: this OR this OR this (a payment is a card, or cash, or an invoice); the checker makes sure every case is covered.
