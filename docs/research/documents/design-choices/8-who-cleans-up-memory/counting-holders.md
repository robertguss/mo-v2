# Counting holders

**Label:** Chosen (D32)

Robert's choice (D32). Each value counts its holders and is freed the moment the count reaches zero. Predictable, no pauses, and it powers D26's in-place updates. Its weakness, cycles, essentially cannot form in a pure language.

* Languages: Swift, Koka, Roc, Lean 4; Python in part.

Cost: a small counting overhead; fine under D27.
