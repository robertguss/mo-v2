# 6 What can code do behind your back?

A side effect is anything a function does to the world outside itself: printing, files, network, email, the clock, randomness, payments. Can a function walk out the front door whenever it likes, or does it need to be handed a key? Also answers where long-lived state lives in a pure language (from choice 3).
