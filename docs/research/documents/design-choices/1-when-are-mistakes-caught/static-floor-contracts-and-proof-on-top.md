# Static floor, contracts and proof on top

**Label:** Chosen (D24)

Robert's choice (D24). No program runs unless it passes the checker, which cannot be switched off. Promises about logic can be stated; they are proven where possible and checked while running where not. This is the SPARK approach.

Why:
* The extra writing effort falls on agents, not people.
* With no human reading the code, whatever the checker misses reaches the running program.
* Mandatory proof everywhere would make some ordinary programs very hard to write.
